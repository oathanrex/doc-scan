01

Executive summary

Most people already carry a scanner in their pocket. What's missing isn't a camera — it's the software layer that turns a photo of a page into something that reads like it came off a real scanner: straight, cropped, and exported as a proper document.

This PRD defines a mobile app that captures one or more pages with the device camera, detects the document's borders automatically, corrects the perspective so the page appears flat, and compiles the result into a single exportable PDF. The scope below covers the MVP feature set, the personas it's built for, functional and non-functional requirements, the primary user flow, key risks, and a phased rollout plan.

Core promise: from opening the camera to holding a shareable PDF should take under 20 seconds for a single page, with zero manual cropping required in typical lighting.
02

Problem & opportunity

People still email themselves photos of receipts, contracts, and forms, then crop and rotate them by hand — or worse, send them as-is: skewed, shadowed, and hard to read. Desktop scanners solve the quality problem but aren't available at the moment the document appears: a signed lease, a whiteboard, a doctor's note.

The opportunity is to close that gap with software rather than hardware. Real-time edge detection and perspective correction are well-understood computer vision problems; the product challenge is making the experience fast enough and forgiving enough that people trust it more than a plain camera photo.

Why now

  • On-device machine learning frameworks make real-time edge detection practical without a network round-trip.
  • PDF has remained the default format for anything that needs to look "official" when shared or printed.
  • Hybrid work has increased the volume of one-off paper documents that need to become digital files immediately.

05

Functional requirements

Each requirement below is written as a self-contained spec with acceptance criteria a QA engineer can test directly.

Automatic border detection MVP

While the camera preview is active, the app continuously analyzes frames to locate a rectangular document against its background and overlays a live outline on the four detected corners.

Given the camera preview is active and a document with reasonable contrast against its background is in frame When the document is held roughly still for more than 400ms Then the app draws an outline on the detected edges within 200ms and enables the capture button Given the detected outline is visible When the person taps and drags a corner Then the outline updates live and capture uses the manually adjusted corners
Perspective correction MVP

After capture, the four corner points are used to compute a perspective transform that maps the document onto a flat rectangle at the page's natural aspect ratio.

Given a photo has been captured with four corner points When the correction step runs Then the output image shows the document as a flat, un-skewed rectangle within 1 second on a mid-range device
Multi-page capture MVP

After each page is captured and corrected, the person can immediately capture the next page in the same session without leaving the camera screen. A running page counter and thumbnail strip stay visible.

Given at least one page has been captured in the current session When the person taps capture again Then the new page is appended to the session and the thumbnail strip updates with the new page selected
Review, reorder & retake MVP

Before export, the person sees all captured pages as thumbnails, can drag to reorder, delete a page, or retake a specific page without restarting the session.

Given a session has two or more pages When the person long-presses and drags a thumbnail to a new position Then the page order updates and is reflected in the final export
Export to PDF MVP

All pages in the session are compiled, in order, into a single PDF file sized to a standard page format, and handed to the device's native share sheet.

Given a session with one or more reviewed pages When the person taps "Export" Then a single PDF containing all pages in order is generated in under 3 seconds for a 10-page document and the native share sheet opens
Image enhancement filters V1.1

Post-capture filters (black & white, grayscale, color-boost) improve legibility of text-heavy pages, applied per page or to the whole session.

Text recognition (OCR) V2

On-device OCR extracts searchable text and embeds it as an invisible layer in the exported PDF, and powers an in-app search across past scans.

10

Frequently asked questions

What does automatic border detection actually do?

It analyzes each camera frame in real time to find the four edges of a document against its background, then draws a live outline so the person can confirm or nudge the corners before capture.

How is perspective correction different from cropping?

Cropping only removes pixels outside a rectangle. Perspective correction also warps the remaining image so a page photographed at an angle appears flat and rectangular, as if scanned straight-on.

Why build a native app instead of a web-based scanner?

Real-time edge detection at a smooth frame rate and reliable camera control are far steadier with native camera APIs and on-device compute than through a browser, and native apps can save directly to the device's file system and share sheet.

Does the app need an internet connection to work?

No. Border detection, perspective correction, and PDF export are designed to run fully on-device, so the core flow works offline. Optional features like cloud backup or text recognition may use network access.
